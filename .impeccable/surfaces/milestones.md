# Project milestones

Mode: Operate. Extension of the incumbent project registry, ADR-0024.
Audience: scoped project managers and readers. Job: review concrete deliveries,
record a deadline, conclude/cancel and explicitly reopen without changing tasks.

## Direction contract

THESIS: A milestone is a named delivery with a real deadline and state. Use a
scannable registry and focused record view, never invented progress charts.

OWN-WORLD: Offwhite sidebar, continuous white working field, gray hairlines, system sans,
restrained blue actions, soft semantic state chips and native labeled fields.
Dark mode uses neutral charcoal equivalents. Inherit the shared operational
track, responsive navigation and visible focus recorded in root DESIGN.md.

STORY: Read the project's delivery list, create a milestone, review its deadline
and change state deliberately. Errors retain original intent or reviewed version.

FIRST VIEWPORT: Back link, page heading and short operational explanation above
the project and bordered list/create sections. Detail shows title, state and
deadline before one edit/state section. Mobile keeps reading order. Native fields
and 24px action separation retain the existing keyboard/focus/recovery grammar.

FORM: User-selected Twenty-inspired operational world, 2026-11-12.
Code-led local extension, no new identity, raster or decorative motion. Exact
deadline preservation and original-intent retry are the signature interaction.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
