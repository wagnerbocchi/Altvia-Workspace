# Private ticket notes

Mode Operate. Extension of tickets and queue-access under ADR-0029.

## Direction contract

THESIS Operators record immutable internal notes only after explicit delegation.
OWN-WORLD: Offwhite sidebar, continuous white working field, gray hairlines, system sans,
restrained blue actions, soft semantic state chips and native labeled fields.
Dark mode uses neutral charcoal equivalents. Inherit the shared operational
track, responsive navigation and visible focus recorded in root DESIGN.md.

STORY Queue configuration reviews the exact note tier independently of role.
Ticket detail presents private text in chronological pages and a clearly internal
composer. No customer delivery or implied role permission.
FIRST VIEWPORT Preserve ticket subject/state and existing action priority. Notes
follow ticket data and lifecycle controls. Mobile keeps the same stacked order.
FORM Code-led incumbent extension, the user-selected Twenty direction of 2026-11-12. Reuse record-list,
work-prose, form fields, feedback and the single ticket write owner. Retain
body/version/key through uncertain writes; retain acknowledged note ID until
authoritative ticket/note reads succeed. No assets, fonts, tokens or motion added.
FINISH unreviewed and undocumented is unfinished; this build ends with the finish
review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
Acceptance includes real persisted browser proof, keyboard, axe, overflow and
desktop/mobile light/dark captures. This extension ships no raster assets.
