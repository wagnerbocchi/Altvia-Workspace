## Direction contract

THESIS An operator selects a permitted queue/customer, reviews a manual ticket,
then manages its independently persisted assignment and lifecycle.
OWN-WORLD: Offwhite sidebar, continuous white working field, gray hairlines, system sans,
restrained blue actions, soft semantic state chips and native labeled fields.
Dark mode uses neutral charcoal equivalents. Inherit the shared operational
track, responsive navigation and visible focus recorded in root DESIGN.md.

STORY Scoped inbox, explicit reference selection, creation review, ticket detail,
assignment, reasoned state changes and immutable history.
FIRST VIEWPORT Inbox prioritizes creation and filter controls above scoped rows.
Detail prioritizes subject/number/state, identity references and current actions.
Mobile follows the same stacked reading order with wrapping text and controls.
FORM Code-led operational extension under the user-selected Twenty direction of 2026-11-12.
Retain original protected POST body/key/version
through uncertain responses and failed reads. Confirm authoritative state before
the next mutation. Keep requester identity visibly unverified.
FINISH Inspect desktop/mobile light/dark, axe, keyboard, overflow and persisted
recovery evidence before final whole-surface review and documentation.

Queue workflow flags use the same reviewed configuration authority as queue data.
The interface makes closure/reopening eligibility explicit without inventing
automatic timers, SLA hours or contact verification.
