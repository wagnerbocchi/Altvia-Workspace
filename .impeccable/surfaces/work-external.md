# External task involvement

Mode: Operate. Narrow extension of the existing work editor and detail, ADR-0025.
Users: scoped managers who identify an outside participant, employees/readers who
need to distinguish that attribution from an internal owner or contributor.

## Direction contract

THESIS: External involvement is supplied task metadata, never an identity or grant.
OWN-WORLD: Offwhite sidebar, continuous white working field, gray hairlines, system sans,
restrained blue actions, soft semantic state chips and native labeled fields.
Dark mode uses neutral charcoal equivalents. Inherit the shared operational
track, responsive navigation and visible focus recorded in root DESIGN.md.

STORY: Enter one outside name per line, save, read the resulting list, and later
review/clear it deliberately through the existing task version and recovery flow.
FIRST VIEWPORT: Existing task heading and work-data section remain primary. Detail
places outside names after internal contributors and before description. The
manager editor adds a clearly labelled multiline field after internal involvement;
plain help explains limits and lack of account/access effect. Mobile retains order.
FORM: Inherit the user-selected Twenty-inspired neutral world from apps-web.md.
Code-led local extension, no new world, raster, comp, global layout or motion.
The signature interaction is retained original external labels during uncertain
creation and an explicit reload after a stale reviewed edit. Native theme controls
must drive capture themes, including browser-native color-scheme.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
