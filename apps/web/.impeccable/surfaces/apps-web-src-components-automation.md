## Implemented interaction

Queue configuration asks for an explicit managed client; the selection grants
nothing. The server retains the complete queue/client authority conjunction.
Creation names its disabled initial state. Native static task title, priority and
eligible ticket-state controls describe the complete configurable action. The
current client default project and current ticket assignee resolve at execution;
private ticket text, ticket state and deadlines are not copied into work.

Rule facts remain readable during activation/deactivation review. Review copy
explains that enabling does not search old assignments and disabling fences older
queued work while preserving existing tasks. Rule mutations retain the original
rule and queue versions with their protected intent. A minimal receipt is followed
by a current scoped read; uncertain completion offers the original verification
or recovery action rather than silently constructing another intent. Selection
and conflicting actions stay locked while their protected operation is pending.

Ticket outcomes use native wrapped record rows with explicit state words,
attempts, time and bounded corrective guidance. Eligible retry reviews the same
original assignment and rule while explaining that current access, project and
assignee are checked again. Acknowledged rescheduling remains distinct from
successful processing. Generated/adopted task links depend on scoped API output;
generic activity identifies automation truthfully without execution/source IDs.
Manual activity labels and separate task/ticket state histories remain native.

Keyboard entry focuses the rule review heading, edit title or retry heading.
Cancel restores the initiating review/edit/retry control. Confirmed results move
to the relevant section heading. Session disposal and current-session guards
prevent old private responses or recovery state from becoming a new identity's
view. Native loading, read-error, empty, paging and protected-write recovery
patterns remain shared; no totals or synthetic operational metrics are added.
