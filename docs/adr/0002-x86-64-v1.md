# ADR-0002: Mandatory x86-64-v1 deployment baseline

Date: 2026-11-08. Status: mandatory constraint; image/runtime homologation pending.

Context: specification reports Ubuntu 24.04.5 LTS KVM/QEMU, 12 vCPUs, QEMU Virtual
CPU version 2.5+, without SSSE3/SSE4.x/AVX/AVX2/FMA/BMI2. Physical host CPU is
unknown. No live VM flags were collected in this session.

Decision: all mandatory binaries run on x86-64-v1. Prohibit Elasticsearch,
OpenSearch and dependencies requiring higher ISA. No Solr, MongoDB, vector
engine or local AI runtime in MVP. Use PostgreSQL FTS/GIN; pg_trgm only when
necessary and tested. No `-march=native`; portable builds specify baseline ISA.

Candidate runtime families only: Node 24 bookworm-slim, Python 3.12 slim,
PostgreSQL 17, Redis 7. Check supported patched releases, native transitive
dependencies and vulnerability reports at build time. Pin actual platform digest
after validating the exact artifact. No tag/digest is approved by this ADR alone.
Job library, object storage and antivirus remain unresolved until validated.

Alternatives: requiring a hypervisor CPU change violates current acceptance
constraints and may break migration. Pull success/amd64 label/emulation on the
workstation does not prove real guest compatibility. No silent fallback or
healthcheck suppression is allowed for SIGILL.

Consequences: native wheel/image selection can require a compatible build or
replacement. Audit Argon2, Pydantic core, SWC/Sharp, TLS/compression, database,
storage and scanning binaries. Keep raw guest evidence and artifact manifest
with command/exit status; see infrastructure-compatibility.md for the gate.
